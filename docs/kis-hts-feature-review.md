# KIS HTS 기능 검토

작성일: 2026-06-01

## 목표

한국투자증권 KIS 데이터를 기존 `stock-robot` 구조에 붙여 HTS처럼 직관적인 후보 감시 화면을 만든다. 단, 화면의 후보는 즉시 매수 신호가 아니라 검증 대상이다.

## UI에 반영한 기능

- 시장 선택: 국내주식, 해외주식
- 후보 필터: 전체, 매수 후보, 수급 동반, 리스크 낮음
- 후보 목록:
  - 종목명/코드
  - 신호 상태
  - 품질점수
  - 수급점수
  - 현재가/목표가/손절가
- 상세 패널:
  - 현재가
  - 목표까지 수익률
  - 손절폭
  - 손익비
  - 외국인/기관/연기금/금융투자/개인 수급
  - 1일, 3일, 7일 검증 시나리오

## 서버에 붙일 기능

1. KIS 토큰 관리
   - `KIS_APP_KEY`
   - `KIS_APP_SECRET`
   - 토큰 캐시 및 만료 전 갱신

2. 국내주식 수급 데이터
   - 외국인 순매수
   - 기관 순매수
   - 개인 순매수
   - 연기금/금융투자 제공 가능 시 분리 저장
   - 프로그램 매매 보강

3. 조건검색 후보 저장
   - HTS 조건검색식 또는 KIS 조건검색 결과를 `KneeStocks`와 별도 컬렉션에 저장
   - 후보 생성 시점 가격, 목표가, 손절가, 수급 스냅샷 저장

4. 성과 추적
   - 다음 거래일 시가 기준 수익률
   - 1일, 3일, 7일 종가 수익률
   - 장중 최대상승률
   - 장중 최대하락률
   - 목표가 터치 여부
   - 손절가 터치 여부

## 수익검증에 쓸 기능

- 조건검색식별 승률
- 조건검색식별 Profit Factor
- 수급 조합별 성과
  - 외국인+기관 동반 순매수
  - 기관 단독 순매수
  - 외국인 단독 순매수
  - 개인 순매도 동반 여부
- 가격 위치별 성과
  - 52주 박스 하단
  - 120일선 이격도
  - RSI 과매도/중립
- 리스크 지표
  - MDD
  - 연속 손절
  - 갭하락 위험
  - 목표 도달 전 손절 터치 비율

## 우선순위

1. KIS 수급 API를 scanner에 연결
2. 후보 생성 시점 스냅샷 저장
3. 1일, 3일, 7일 추적 컬렉션 추가
4. UI에 실제 완료 통계 추가
5. 표본 100건 이상 쌓인 뒤 필터를 매수 신호 후보로 승격 검토
